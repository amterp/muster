## New

- **Agent list entries are taller and the list is narrower.** An entry takes up to four lines: the
  agent's state and machine, then its name or title, then its helpers as pills, one per helper, in
  a single list that includes helpers of helpers. An agent without helpers has no pills line. The
  list starts 200 points wide in a new window; a window you already have keeps its width until you
  drag it.
- **The working icon turns.** It is a ring with a gap that turns once every four seconds. It holds
  still under Reduce Motion.
- **The Needs you strip sits under the agent list**, so cards coming and going no longer move the
  agents' rows.
- **The Messages section is gone.** Right-click an agent's row, its hidden row or its pane and
  choose Conversations to open, leave or delete a conversation with that agent. Window >
  Conversations lists every conversation you are in, including those with several members and
  those whose agents have closed. Anything unread still reaches you through Needs you. An agent's
  own Conversations menu lists only its one-to-one conversations for now.
- **Closing a pane or tab that holds an agent asks first.** Return confirms Delete Group too.
- **`muster window` says when Codex's copy of Muster's adapter is out of date**, and names the
  command that refreshes it: `muster harness install codex`. `--json` gives it as
  `adapter_copies`.
- **Compaction thresholds by harness, directory and pane, and a nudge before them.** `compact_at`
  can be set under `[harness.<name>]` and in `[[directory]]` blocks as well as at the root, and
  `"none"` turns it off for that harness or directory. A new key, `compact_nudge_at`, has Muster
  message an agent to compact itself before `compact_at` does it for it; Claude Code only for now.
  `muster pane compaction` sets either for one pane, such as an agent's own or its helpers', and
  with no flags says what applies and where it comes from. `muster docs configuration` has the
  details.
- **An agent's helpers close with it.** When an agent's pane closes, each of its helpers closes
  once it has been idle or done for 10 seconds, and their helpers with them. A helper still at work
  keeps running until then, and can ask for you meanwhile. Reopening the agent (`cmd+shift+T`,
  `muster pane reopen`) brings its helpers back too, hidden and quiet as before. To keep a helper
  open, bring it on screen or reopen it on its own. Helpers left behind by agents that closed
  before you updated close the same way once the new daemon starts, and can be reopened within the
  hour.

## Changed

- **The daemon protocol is 1.14.** Until a devenv's daemon is updated, it sends no compaction
  nudges, and it compacts at the root `compact_at` only when no harness or directory rule sets
  `compact_at`; otherwise it does not compact by threshold at all.

- **A reply sent from a banner takes the banner down** and clears the conversation's card from
  Needs you.
- **The Needs you strip names agents in other windows** and shows a blocked agent's subtitle
  wherever it runs. `muster window --json` gives each `asking` entry's `callsign`, `label` and
  `subtitle`.
- **A `muster msg wait` ends when the pane that ran it closes**, and a Stop hook's `--due` wait
  ends when its agent starts a new turn, so a message is no longer delivered twice.
- **A wait declared with `report --waiting --until-message-from <pane>` ends** once that pane has
  answered in the agent's current turn or has closed.
- **`muster msg post --as` accepts the caller's own pane**, and `muster msg post` reads flags that
  come after the message text instead of sending them as part of it.
- **`muster daemons` answers without a window**, reading the daemons recorded on this machine.

## Fixed

- Claude Code's Heads up notice no longer holds an agent's wakes or compactions.
- A wake or rename left unsent in an agent's prompt gets its Return pressed again, instead of
  holding every later wake to that pane.
- A Claude Code session no longer reads as working after its turn ends because a background
  sub-agent is still calling tools.
- A relaunched window puts its tabs back in their saved order, including a tab that spans two
  machines.
- A stack of banners taller than the window scrolls.
- A pane reattached while its program was partway through an escape sequence or a multi-byte
  character no longer prints the rest of it as text.
- Lifting a key no longer raises a false "painting stopped" problem for the pane.
- An unnamed pane's row no longer says its directory twice.
