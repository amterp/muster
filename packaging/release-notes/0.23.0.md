## New

- **The API says when an agent's context was cleared or compacted.** API 0.4 adds
  `Pane.context_change`, which holds the last of the two to happen and when the daemon heard of it.
  Claude Code reports a clear at `/clear` and a compaction just after it finishes. Codex reports a
  compaction as it finishes, and a clear at the first prompt after `/clear` or `/new`, because it
  runs no hook before that prompt. OpenCode reports neither yet.
- **The API says when a pane's name came from its session.** `Pane.name_from_session` lets a client
  hide a title a harness wrote about a wake, such as "Read galaxy+ocean message". Renaming a pane in
  Muster clears the mark. A person's `/rename` in Claude Code carries it too, so rename in Muster to
  keep a name in such a client.

Clients of API 0.3 keep working.

## After upgrading

Run `muster harness install claude-code` and `muster harness install codex`, then restart the
sessions you want reporting: the hooks changed. A stale adapter reports nothing and doesn't say so.
