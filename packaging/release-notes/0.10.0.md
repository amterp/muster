**Muster now runs its own session daemon, muster-daemon, in place of herdr.** Read this before updating: the
panes you have open now do not carry over.

- **Your open panes stay with the old daemon.** The herdr daemon an earlier Muster started keeps running after you
  update, and so does everything in its panes, but no window of this Muster can show them. Finish that work before
  you update.
- **Your windows come back without their tabs.** Each window's size and place, whether its agent list was open, and
  the SSH machines it was attached to are read from the old arrangement. The tabs are not, since they lived in
  herdr.
- **`muster daemons` lists each old daemon as `herdr`**, with the command that ends it:
  `kill $(lsof -t <socket>)`. Ending one ends every pane it holds.
- **On an SSH machine**, the old herdr under `~/.muster/herdr/` keeps running too. Muster installs its new daemon
  beside it the first time you attach, with nothing for you to install. `pkill -x herdr` on that machine ends the
  old one and its panes.
