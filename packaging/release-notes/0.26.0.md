## New

- **A machine that is down keeps its panes' places in a tab.** A window opened while a machine
  is unreachable draws a placeholder where each of that machine's panes belongs, naming the pane
  and the machine. When
  the machine answers, each placeholder becomes its pane and nothing else in the tab moves.
  Right-click a placeholder and choose Remove from Tab to take it out; if the machine answers
  later, that pane comes back in a tab of its own. Taking a machine out of `config.toml` removes
  its panes from every tab at the next launch.
- **`muster pane remove --pane <id>`** does what Remove from Tab does, from the CLI. `muster
  window --layout` prints the id in the placeholder's box.
- **The pane menu splits onto another machine on any side.** "Split Right on", "Split Down on",
  "Split Left on" and "Split Up on" each list the machines, in place of "Split on Machine", which
  split right only.
- **Muster tells you when a message has waited 30 minutes on a pane only you can free.** That is
  a pane at a dialog, or one whose prompt something covers. The notice comes once, from `@muster`
  in your conversation with that pane, and names `muster pane show --pane <callsign>`. The
  posters are still told after 2 minutes, as before. A helper's maker is told first, as before;
  if the helper is still at its dialog 30 minutes later, Muster tells you, once. A pane blocked
  with no message waiting on it still gets only the `blocked` notification.
- **`muster pane compact` works for Codex.** Muster types `/compact`. A focus is refused for
  Codex, which sends words after `/compact` to the model as a message. Codex's context reading is
  now fresh after a compaction.
- **Codex and OpenCode panes come back in their sessions with their flags** after a daemon
  restart or `muster pane restart`. A Codex pane used to come back with its default sandbox and
  approval mode, and an OpenCode pane as a shell.
- **An agent can delete, pause and resume a group kept on another machine.** The request is
  carried to the machine that keeps the group and done there as that agent, under that machine's
  policy. `muster msg group set`, `add` and `remove` are still refused from elsewhere, and the
  refusal now gives the command to run on the group's machine.

## Changed

- **libghostty is at vt-1.0.0**, 1616 upstream commits past the previous pin. It fixes memory
  errors in the daemon's terminal (an out-of-bounds write when narrowing a split wide character,
  a use-after-free in print, stale style and hyperlink ids after a scroll clear) and a whole-app
  freeze during display sleep or wake. Upstream measured parsing 1.3 to 3.7 times faster. Six
  keys that sent nothing to a program using modifyOtherKeys 2 now send xterm's encodings.
- **The daemon protocol is 1.15.** Until a devenv's daemon is updated, an agent's group delete,
  pause and resume are not carried to it, and the refusal says to update Muster there.
- **`muster window --json` marks an unreachable machine's pane** with `"unreachable": true` on
  its `tabs[].layout` leaf, and `--layout` draws its box as `unreachable`.
- **A pane reads `blocked` about 300 ms after its dialog appears.** Claude Code's plan dialog
  ignores a Return for the first 60 ms or so after it finishes drawing, so a key sent the moment
  `muster pane wait --until blocked` answered could be lost.
- **libghostty-vt is compiled into the daemon and the core** on a Mac, as it already was on
  Linux. The bundle no longer carries `libghostty-vt.1.dylib`, and a remote Mac's install is the
  daemon, the CLI and the data directory. The daemon grows from 10.1 to 11.5 MB.
- **Building from source no longer needs Zig installed.** `./dev` fetches the Zig that
  `deps/zig.pin` names into `~/.cache/muster-zig/`, and ignores a `zig` on your `PATH`.

## Fixed

- An urgent post typed into a working agent's prompt no longer sits there unsent for the rest of
  its turn. Muster presses Return again through the turn, at intervals growing from 5 seconds to
  2 minutes, while the prompt holds only that notice. If it is still unsent after 30 minutes, the
  notice to the sender says so and gives the command that sends it.
- A linked machine's `@muster` notice about a helper goes in the group the helper and its maker
  already share. It used to open a second group, such as `bison+wren@mac`, after which every
  `muster msg post --to` between the two needed `--group`.
- A notice that a helper is blocked, or that a message sits unread, is no longer delivered after
  the dialog was answered or the message read. Muster holds it while the agent it is for is busy,
  and drops it if it no longer holds.
- Codex at a list it asks a question with, such as `/new`'s "Where should the new conversation
  run?", reads `blocked`. It read `done`, so `muster pane wait` answered at once and a posted
  message was never taken.
- An agent that produces no output is found even when Muster first looked at its pane while the
  agent was still starting.
- Option+Backspace reaches a program using the kitty keyboard protocol as `CSI 127;3u`. It
  arrived as a bare DEL, so it deleted one character where the program meant a word. Outside
  that protocol it is still ESC DEL.
- Resize and Even Out in a tab that spans machines move the dividers the window draws. In a
  window that leaves a machine's panes out, they could pick a divider beside a pane it does not
  show.
- A replayed pane keeps a pending line wrap when the cursor's cell is blank.

Changes to the test suites and the build that do not reach an installed Muster are not listed.
