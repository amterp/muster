## New

- **The agent list is redrawn.** Each agent's state is a shape as well as a color, the chord that
  reaches it is drawn as keycaps, and its second line keeps the directory whole before anything
  else shrinks. A long name ends in an ellipsis, with the full name on hover. The context bar is
  longer. The list starts 280 points wide in a new window.
- **Every pane has a header.** It shows the pane's chord, state, callsign, name, how long the state
  has held, and its context bar. A blocked or stuck agent's header is tinted. Panes now sit flush,
  and the only border marks the pane the keyboard feeds. Drag a pane by its header to move it. A
  pane under 60 points tall has no header and is dragged by its row in the agent list.
- **A strip at the top of the agent list says who wants you.** It has one card for each blocked,
  stuck or finished agent, each program notification, and each group with a message for you, in
  the order `cmd+shift+a` walks them. Click a card to go there. The strip is gone while nothing asks,
  and folds to one line of icons.
- **Tabs fold in the agent list.** In a window with two or more tabs, the chevron on a caption folds
  that tab to a row of its agents' state icons, so a blocked agent inside still shows. The chords
  still reach a folded tab's agents.
- **A conversation with one agent sits on that agent's row.** An envelope on the row shows the
  unread count and opens the conversation; right-click it to leave or delete the group. Its banner
  is named after the agent. A group with several members, or one whose agent's pane is in another
  window or closed, stays under Messages.
- **Conversations and banners are restyled.** They take the terminal's background and text colors.
  Each author has an avatar in a color of their own, the same in every group and window. A message
  to you has an accent bar and a "To you" tag. A banner's time shows seconds, and banners after the
  first fold into one line naming who they are from.

## Changed

- **`cmd+shift+a` and `muster focus --asking` also go to stuck agents and messages for you**,
  in this order: blocked, stuck, messages for you, program notifications, done.

## Fixed

- A pane started in a directory reached through a symlink, such as `/tmp`, no longer shows its
  directory change to the resolved path a moment after it opens.
