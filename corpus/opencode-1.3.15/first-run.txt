What OpenCode 1.3.15 draws at its prompt, what it does with a pasted line and a Return, and which
model it picks, run in a pseudo-terminal with no paid credentials reachable.

Recorded 2026-10-04 on macOS 26.4.1 / arm64, opencode 1.3.15 (~/.opencode/bin/opencode), in a
100x30 pseudo-terminal driven by scratch scripts built on `tools/detection-capture.py`. The
machine's only stored OpenCode credential is an OpenAI login, so after the first run every run
pointed XDG_DATA_HOME, XDG_CONFIG_HOME, XDG_STATE_HOME and XDG_CACHE_HOME at scratch folders:
OpenCode found no credentials, and no turn could reach a paid account.

Its prompt, idle (paths shortened):
                 ┃
                 ┃  Ask anything... "Fix broken tests"
                 ┃
                 ┃  Build  <model> <provider>
                 ╹▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀
                                       tab agents  ctrl+p commands
    the suggestion "Ask anything..." is drawn faint; "half typed", typed as keys, takes its place

Which model:
    with the user's own data: "-m opencode/minimax-m2.5-free" drew "Build  GPT-5.4 OpenAI · xhigh"
    (the stored OpenAI login); no turn was sent
    with scratch data: "-m opencode/minimax-m2.5-free" drew "Build  Nano Banana Pro Google"
    with scratch data and {"model": "opencode/minimax-m2.5-free"} in the scratch opencode.json:
    the same - neither the flag nor the config chose the model the TUI used

A line pasted and a Return, in one write, as the doorbell rings an idle agent:
    ESC[200~Reply with the single word hi.ESC[201~ CR
    25 s later the line still sat in the prompt, unsent
The same paste, then a Return 1.5 s later in a write of its own:
    the turn started: "▣  Build · Nano Banana Pro", then "Google Generative AI API key is
    missing..." - the model had no key, so nothing was spent
Typed while the failed turn's screen showed: "and then say done" sat in the prompt.

No turn of a model that answers was recorded, so neither a working screen nor what OpenCode's
plugins report was measured.
