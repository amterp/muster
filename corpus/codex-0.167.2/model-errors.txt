Codex 0.167.2, macOS arm64, 2026-11-13, 80x24 panes of isolated daemons.
Each case has scratch HOME/CODEX_HOME and project hooks: this checkout's state adapter plus
recording hooks for SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, PermissionRequest,
Stop, Interrupt and SessionEnd. Recording hooks run before adapter hooks for the same event.
Codex starts --no-daemon --dangerously-bypass-hook-trust -a on-request -s read-only.
All cases use gpt-6.1-terra through an explicit custom Responses provider, updates disabled.
No real model or user account is contacted. Prompt: Reply with the single word hi.
State is sampled about once per second; a multi-case loop can take longer around CLI calls.
State times below are from immediately before pane send. Hook times in the JSONL companion
are from UserPromptSubmit; native event times use its wall-clock timestamp instead.
Private paths and session IDs in the committed data are placeholders.

Connection failure: http://127.0.0.1:9/v1 (the port refused a connection before the run).
Default provider retry settings: still reconnecting at 361.188s, working/reported, no wait.
Explicit request_max_retries=0 and stream_max_retries=0: same at 360.568s.
Only SessionStart and UserPromptSubmit fire before the cap in each case.
At the cap, the driver sends Esc. Interrupt then fires; the native rollout records
turn_aborted(reason=interrupted), not a natural task_complete. No Stop appears.
Afterward, a local ! printf command displays UNREACHABLE_INPUT_OK. Its input contains only
octal escapes for that string, so seeing the decoded line proves execution, not just arrival.
The natural give-up outcome for connection failure is not reached in this observation.

HTTP controls: independent custom loopback servers return 400 or 503, with both provider retry settings zero.
The native duration_ms values are 104 ms (400) and 77 ms (503), with no assistant message.
Neither case fires Stop or Interrupt before the local input check more than 30 seconds later.
Muster initially retains working/reported, then first samples done/unreported at 10.7 s (400)
and 10.4 s (503). No declared wait is present. Both accept the local shell input check.
These controls establish HTTP-error termination only, not connection-refused termination.
